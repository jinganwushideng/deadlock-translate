# 0.7.0 验证范围

0.7.0 包含新的原生风格设置界面、自动保存、三种设置背景、重载保护和发送关框／新草稿隔离。最终构建编号、文件校验、安装器载荷与正式发布结果以 release/0.7.0/release-verification.json 为准。

相同功能代码在升级版本号前已由 GPT-6.1 Terra 完成本机实机检查：半透明模式能辨认真实大厅角色、窗户、吊灯与地面；实时模糊透出对应色光，文字和控件仍可读；静态模式不透明。重新加载后页面正常、关闭设置后大厅菜单和好友栏恢复。这些结果发生于 0.6.25 功能候选，不能当作 0.7.0 新二进制在所有机器上的全面验收。

本次还会对 0.7.0 进行版本／历史记录、发送状态、原位输入、后台、VPK 配套、公开源码与完整安装器的离线及隔离检查。用户此前确认的真实翻译发送与服务网络结果仍只适用于对应候选；本次不自动向游戏玩家发送聊天。

透景使用游戏侧兼容合成，并非恢复网页纹理的逐像素透明通道。场景会影响面板颜色，实时模糊会弱化场景轮廓；性能和完整闪烁压力测试尚未完成，不宣称 FPS 提升。安装器的包验证／隔离启动不等同于在用户机器重新安装证书或覆盖游戏。

# 0.6.25 验证范围

本版正式构建包含原位中文输入、发送频道确认、专名纠正／一次重译以及网络分类与安全重连。最终构建编号、运行 ZIP、内置安装载荷与哈希校验结果记录在发布目录的 release-verification.json。

相同功能代码在升级版本号前完成了 936 项相关离线检查。该数量包括模拟服务、模拟游戏控件与隔离浏览器回归，不代表 936 次真实游戏测试。当前正式构建另外运行版本、历史记录、安装器、包校验及更新／回退测试；最终结果以发布验证文件为准。

本机已实测单行、多行文字框用拼音输入中文、自动回填与 Esc 撤销；用户手动发送测试句成功，日志显示组队频道两条消息在约 3.14 秒内完成游戏端提交。这些实测发生于相同功能代码的 0.6.24 候选，不能当作 0.6.25 新二进制、所有用户网络或游戏服务器送达的全面验收。未测量 FPS 改善。

已知限制：原生文字框编辑时，滚轮可能被输入控件接管，先点击空白处即可继续翻页；进入／退出编辑时兼容提示区域可能产生轻微位移。旧用户网络日志未包含足够的底层错误码，无法事后确定具体 DNS／代理／TLS 原因；本版增加分类与恢复范围，仍需在反馈者机器复测。

## 实机范围与限制

本机此前的同实现修订已用于检查游戏聊天和设置入口；最新测试日志有 1、2、5 段顺序提交记录，每段均不超过 80 字符。关闭分段的前缀模式已通过隔离后台与设置页自动测试，尚需本版实机确认。不同游戏版本、分辨率、其他 Mod 组合、服务商接口以及完整快捷短语/分条发送组合仍需要实机验证。

气泡日志中的尺寸恢复仅代表控件布局采样恢复，不能证明屏幕像素始终可见。脚本耗时是墙钟时间，不是游戏 FPS；本版不承诺固定的平均帧数或 1% low 提升。

游戏原生频道与限流决定最终送达；“已交给游戏”表示提交调用已完成，不能保证所有玩家已经收到。已经提交的分段不可撤回。
