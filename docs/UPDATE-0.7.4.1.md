# 0.7.4.1 · 安装器与启动兼容修复

- 修复证书准备时提示找不到 `powershell.exe` 的问题。证书准备、续期、卸载和外置更新器现在使用 Windows PowerShell 的完整路径。
- 恢复普通 Steam 启动和管理员兼容两种选项。游戏确需管理员权限时，可启用兼容模式并确认 Windows UAC。管理启动项会保留 Steam 账号原有的兼容模式。
- 修复旧安装流程从含方括号的离线包目录复制文件失败的问题。已有安装器运行时，后台启动检查会返回占用状态。

## 如何更新

退出 Deadlock，下载并运行 `DeadlockTranslate-Setup-0.7.4.1.exe`，选择「安装 / 覆盖更新」。安装器内置完整离线包，现有个人配置、密钥、证书和词库可沿用。

已在隔离 Windows 环境验证空 PATH、特殊目录名、并行解包和安装器占用。实际 Windows UAC 确认和受影响电脑的安装结果仍需实机验证。
