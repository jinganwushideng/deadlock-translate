# 0.6.25 更新说明

相对 0.6.24 的最终改动：

- 游戏内设置增加原位中文输入：文字框直接使用游戏原生输入法，点击别处自动回填，Esc 撤销当前编辑，保存后生效。
- 改善关框后频道标记暂时消失造成的发送等待；每条任务保留原频道，重新打开聊天或频道冲突时重新确认，不改发其他频道。
- 发送精翻增加本地专名格式和明确别名纠正；仍缺少必需名称时最多重新翻译一次，保留原有思考设置、输出预算和总时限。
- 为能够确认尚未建立连接的临时 DNS／连接错误增加一次重连；响应已开始、连接重置、TLS 错误或提交状态不明时不盲目重放。
- 设置页区分 DNS、代理、HTTPS 验证与响应中断等失败原因，诊断日志增加脱敏网络类别、错误码和频道确认依据。

## 更新方式

退出游戏后运行 **DeadlockTranslate-Setup-0.6.25.exe**，选择“安装 / 覆盖更新”。后台、设置页和游戏 VPK 一起更新，保留原配置、密钥、证书及用户词库。已有有效证书无需重复安装。

安装器首次打开本版本会显示更新说明，底部“更新日志”仍可查看旧版本记录。QQ 群 **923443423** 可反馈问题、获取及时更新。

## 使用说明

- 文字框中的内容结束编辑后仍是页面草稿，需要点击“保存设置”或词库页内的“保存词库”。编辑中滚轮未翻页时，先点空白处再滚动；进入／退出编辑时可能有轻微排版位移。
- 专名修复可能增加一次 API 调用；模型仍漏名或超时就保留原文，不发送错误或残缺结果。
- 真实服务的网络故障仍取决于服务商、代理与本机网络。日志中的提交事件不是游戏服务器送达凭据。
