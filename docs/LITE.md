# 同频精简版

退出 Deadlock 后运行精简版安装器。正常从 Steam 启动游戏，在「翻译设置」里可以打开接收翻译、发送翻译、游戏词库和作者信息。

- 文字收发默认使用免费翻译。需要大模型时，在收发页面选择对应引擎。首次配置服务时填写 API 密钥。
- 接收译文跟随原消息，打开聊天记录可回看。
- 发送默认只发译文，可以附上原文。超长消息按当前频道顺序续发。
- 从完整版切到精简版时，直接运行精简版安装器。安装器会带入个人词库、收发语言、发送键、收发开关、双语选项和大模型服务配置，以及同一 Windows 用户保存的大模型 API 密钥。早期精简版也可直接覆盖升级。精简版的大模型服务未配置时，会补迁本机保留的完整版配置和密钥。各版本保留自己的收发引擎选项。
- 「作者信息」里可检查精简版更新。精简版从 0.1.0 独立编号。

## 发布约定

GitHub 正式发布使用 `lite-v0.1.0` 这样的标签，上传 `DeadlockTranslate-Lite-Setup-0.1.0.exe` 与对应的 `.exe.sha256`。发布时取消仓库的「最新发布」标记，完整版由仓库的最新正式发布提供更新。
