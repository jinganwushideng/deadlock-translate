# 0.6.23 使用说明

0.6.23 安装器支持首次安装与覆盖更新，成套包含后台、设置页和游戏 VPK。具体修订以设置中的构建编号为准；安装和更新保留个人设置、密钥与证书。

## 模型与思考

“翻译服务”的大模型区域使用“通用 / 接收 / 发送”三个标签，标签旁提供“启用独立配置”开关。关闭时统一使用通用模型与思考，接收/发送标签置灰但保留原值；开启后分别编辑和测试。模型留空或思考选择继承时沿用通用配置。旧配置已经填过独立模型或思考时升级保持启用，未单独设置的用户默认共用通用配置。

两方向共用 API 地址、密钥、输出上限、思考接口格式与服务并发额度；完整填写服务商模型 ID。切换到不支持思考开关的服务时，是否生效仍取决于提供方协议。连接测试跟随当前标签，按钮明确显示测试通用、接收或发送配置；切换标签或修改输入会使旧结果失效。测试使用当前页面草稿，不自动保存。

## 分条发送

两个开关默认关闭：

- 双语分条：在“原文＋译文”模式下，先发原文，再发译文；同样内容只发一次。
- 超长分条：单条超过游戏输入框的 80 个 Unicode 字符（包括空格、标点和组合符）时，优先在空格或标点处分段，不切断代理对、组合符或表情序列。最多 8 段；开启时完整分条，超过总上限或单个字符组合无法容纳时提示失败。关闭时发送当前单条能容纳的前缀，不切断组合字符，完整原文与译文仍保留并提示未发送字数。

每段都使用提交时的频道。后台收到当前段确认后才提供下一段；同频道后续任务等待整条任务提交完毕。分段与快捷短语的连续提交至少间隔 0.9 秒，玩家正在输入时暂停。切局、超时、频道不明、关闭发送或提交异常时停止剩余内容。已经提交的部分无法撤回，游戏自己的限流仍可能影响实际送达。

界面显示当前段及总段数。收到游戏事件调用的成功结果只表示已提交给游戏，不代表其他玩家一定收到了消息。旧游戏脚本未声明分段能力时，后台不会只发送第一段。

## 快捷短语

“快捷键与短语”可保存最多 10 条，每条包含最终文本、快捷键、当前频道/友军/全体/队伍（组队）和启用开关。默认沿用上次使用的游戏频道；第一次使用前先打开并关闭一次聊天框。选择固定频道后，若游戏当前频道不同且不能可靠切换，会等待并显示处理方法，超时停止；不会改发其他频道。不调用翻译 API，可直接填写中文、英文或其他语言。

- 游戏在前台、聊天框和翻译设置关闭、连接新鲜且游戏与后台构建一致时才能触发。
- 使用现有 Windows 键盘监听，不新增常驻进程。启用快捷短语且构建匹配时，空闲游戏心跳从 2 秒缩短至 0.5 秒；无启用短语时维持原间隔。录制只填草稿，保存后才生效。
- 长按只触发一次，重复触发至少间隔 0.9 秒；丢失松键事件时由现有维护回调核对物理键状态。
- 保存时检测快捷短语之间及与翻译发送键的冲突，包括 Ctrl 和左/右 Ctrl 的重叠。仍需玩家避开游戏原有按键。
- 短语按键绑定当前游戏会话，超过 3 秒尚未被后台领取的按键不补发。文本进入现有发送队列后遵循相同频道、过期与跨局保护。
- 开启超长分条后快捷短语也可分条。短语保存在本机设置，诊断只导出数量和开关，不包含短语正文。

## 词库预览

“游戏词库”中输入测试句，选择接收/发送及快译/精翻，可查看已保存词库中的专名保护、短语提示、歧义未解和长词重叠。当前/旧中文名及双语显示使用页面对应选项。点击“定位词条”可筛选编辑，编辑词库后先保存再测试。

预览只在本机执行，不调用云端、不发送聊天、不记录测试正文。它解释确定性词库处理，不预言大模型最终译文；歧义项仍需要模型结合上下文判断。

## 显示、性能与诊断

保留已有 1px 气泡根尺寸微调。日志新增 `hud-nudge-start`、`hud-nudge-recovered`、`hud-nudge-failed`，记录实际采样的前后尺寸和耗时；失败 count=4 表示微调后仍零尺寸，count=5 表示尺寸或恢复接口不可用。微调按有界批次合并，冷却期间不会直接绕过微调触发折叠；复用消息清除旧标记。根原有代码尺寸会在恢复时保留。

`recovered` 仅代表采样尺寸恢复，不是 GPU 像素可见证明。实际自动显示仍要在不按 Tab、不切窗、不额外开关聊天框的条件下验证。

根控件查找分批执行，每次最多 64 个遍历步骤，并优先检查首尾各 16 个直接节点；跳过聊天历史子树。节点与时间预算限制单次工作，未完成部分在后续回调继续。显示保留每次最多两条记录的上限，并在耗时较大时延后第二条。

最近约 30 秒使用固定六个 5 秒桶，分别统计查找、读取、显示、通信最大墙钟耗时及超过 8ms 的回调次数。这包含线程被系统暂停的时间，不能当作游戏 FPS 或确定的卡顿原因。

## 构建编号与后续发布

`python scripts/build_identity.py` 根据可发布源码生成 `build-info.json`、后台常量与游戏脚本编号；`--check` 只检查。普通开发编译前先运行它，正式 `scripts/build.ps1` 会自动执行。

设置页、健康检查、诊断导出、启动日志及安装器显示构建编号。后续便携包制作要求运行目录、源码编号、构建清单和实际文件哈希一致；GUI 安装器要求内置包编号一致。源码变化后不允许通过 ModOnly 把旧后台与新 VPK 混装。个人设置、密钥、证书以及外部工具不参与公共源码编号。

## 游戏验收

1. 气泡：短句、长句、连续消息、缓存命中；不借助 Tab/切窗检查自动显示、无闪烁、无重复弹出。
2. 分条：友军、全体、组队各测双语两条与长译文；同频道有后续任务时顺序正确。
3. 取消：分条期间开始打字、切换频道、切局及关闭发送；不得抢输入、改发全体或补发旧局内容。
4. 快捷短语：录制 Alt 组合、长按、快速重复按、切窗、录制取消及关闭设置；不在其他窗口或聊天编辑时误发。
5. 性能：固定场景比较禁用/启用 Mod 的帧时间及 1% low，并对照分项耗时。离线遍历测试不代替 PvP FPS 验收。

程序与安装包均使用 0.6.23 版本号；校验文件与构建编号随包提供。


设置入口优先定位并缓存；入口缺失时限频重试，不改变原生菜单和 QOL 排版。


## 设置分类

- 概览：本次运行状态和常用入口，不放配置表单。
- 接收翻译：启用、翻译范围、目标语言、快译/精翻模式与接收风格。
- 发送翻译：目标语言、发送方式、双语与分条、语气和大小写、上下文及最近发送任务。
- 快捷键与短语：发送快捷键录制/检测、最多十条快捷短语。
- 翻译服务：服务地址/密钥、大模型三个配置标签与独立开关、快译服务、连接测试与试译。
- 游戏词库：专名英文附注、新旧译名、词库匹配预览和词条编辑。
- 显示样式：自己的译文显示、气泡/独立栏、角色与账号信息、大小/透明度/位置及游戏内预览。
- 性能与队列：共享并发与超时、发送队列、扫描间隔、最近分项耗时。
- 诊断与日志：连接/证书、构建、消息读取与显示证据、近期精翻请求、通信兼容、管理员/Steam 启动及停止后台。

分类切换只切换页面，不保存或重置表单。离开显示页结束临时预览，离开快捷键页结束按键录制；所有修改仍统一点击“保存设置”。

左侧标签栏下方新增固定“保存设置”，与页面底部按钮共用一次保存请求。编辑后提示未保存，保存中两处同时禁用；成功/失败同步反馈。词条编辑仍使用词库内的“保存词库”。
