# 0.7.6 · 队友语音字幕与快捷键语音输入

退出 Deadlock 后运行 `DeadlockTranslate-Setup-0.7.6.exe`，选择「安装 / 覆盖更新」。已有设置、词库和密钥可以沿用。

- **队友语音字幕**在说话过程中显示转写。选用大模型翻译时，译文逐步更新。识别不完整时可在 15 秒内用完整音频补识别上一句，新报点优先显示。
- **快捷键语音输入**可在聊天框关闭时录音。再次按开录键发原文，用翻译发送键发译文。队伍和全体可分别设键。
- **词库保存**支持为同一个标准英文名添加多个昵称。词表说明了匹配词、中文译名和标准英文名怎么填。新增的「女巫」在明确报点时可译为 Vindicta。

队友语音翻译与快捷键语音输入均默认关闭，可以分别开启。进入「接收翻译 → 队友语音翻译」，下载所选模型，保存语音设置，再打开「启用队友语音」。可从 Small Q5_1 和 Vulkan GPU 开始。选择「仅转写」可只显示原文字幕。选择免费翻译或大模型翻译后，转写文本会发送给所选服务。

**帧率影响**　语音识别会占用 CPU 或 GPU，游戏帧率可能下降。模型越大通常越耗资源，实际影响随选用设备和对局负载变化。可选较小的模型减轻影响。

游戏左上角的语音测试窗口默认关闭。手动开启后会显示发言检测、采集、识别和翻译状态，后台重启后会关闭。

选择 NVIDIA CUDA GPU 时，缺少 cuBLAS 会出现「下载 CUDA 加速组件」按钮。首次下载约 401 MB，组件保存在同频本地数据目录。CUDA 不可用时会回退到 Vulkan GPU，语音设置会显示实际使用的设备。

音效和播报与队友语音重叠时，字幕可能漏字或误判语言。
