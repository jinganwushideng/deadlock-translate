# 同频 0.7.2 更新说明

游戏重装迁移与安装恢复（2026-11-06）

相对已发布的 0.7.1：

- 游戏重装或更换目录后，自动备份旧记录并迁移到当前游戏，成套恢复后台、设置页与 VPK，无需先手动删除安装记录。
- 原游戏目录失效时，自动采用唯一检测到的有效游戏；找到多个目录时保留选择，避免装错游戏。
- 旧游戏已删除或不完整时，仍可卸载本程序的失效记录；旧 VPK 只在哈希确认归属后备份停用，其他 Mod 和游戏配置保留。
- Steam 自动配置失败不再阻止核心安装，完成页提供完整启动项供复制；未完成事项单独列出，可重新运行安装器重试。
- 迁移过程检查文件变化并在失败时回退；安装日志补充新旧目录、恢复路径、子脚本失败类别和退出码，不保存原始终端输出。
- 安装器的更新日志和更多选项新增 GitHub 项目入口。游戏内「翻译设置 → 概览 → 反馈、更新与作者」也可打开项目或复制地址。

## 使用

退出 Deadlock，运行 **DeadlockTranslate-Setup-0.7.2.exe**。游戏重装后选当前游戏位置，在检查页核对新旧目录，直接执行安装或修复；无需先删除个人数据或卸载。

原记录、文件备份位置会写入安装日志。若 Steam 自动配置失败，先在完成页复制完整启动项，再粘贴到 Steam → Deadlock 属性 → 启动选项；原有普通游戏参数放在末尾。

## 保留与验证

退出 Deadlock 后运行本版安装器，选择安装 / 覆盖更新或修复；个人设置、密钥、有效证书和用户词库保留。

目录不明确、游戏仍运行、文件被占用、权限受限或 Windows 阻止执行时，仍需确认具体条件；安装器不会替用户关闭安全防护或覆盖未知文件。

恢复与回退已通过隔离文件检查；反馈者电脑的最终安装结果仍需实际验证。旧版更新日志保留。
