# 0.6.23.1 更新说明

- 修正发送长度判定，按游戏单条 80 个 Unicode 字符处理，空格、标点计入，不切断组合字符与表情。
- 关闭自动分段时发送当前单条能容纳的前缀；开启时完整分条续发。双语分开发送时，原文与译文分别按上限处理。
- 最近发送任务显示每段字符数和未发送字数，完整原文与译文仍保留；诊断日志新增匿名长度信息。
- 提交前核对游戏输入框实际内容，遇到意外截短时停止提交并给出处理提示。

## 使用方式

在“发送翻译”调整“超过单条上限时自动分条续发”。关闭时仅发送当前单条能容纳的前缀；开启时按最多 8 条完整续发。双语分开开关独立生效，原文与译文各自处理。完整原文、译文仍保留在最近发送任务中。

- 双语合并仍按原文在前；原文占满单条容量时，该条可能只包含原文。
- 使用本版安装器或随包新版覆盖更新.cmd 升级；后台、设置页和游戏 VPK 需成套更新。

游戏服务器可能限流；客户端提交完成不等同于所有玩家均已收到。配置、密钥和有效证书沿用，无需重复安装证书。历史版本说明见安装器“更新日志”或 CHANGELOG.md。
