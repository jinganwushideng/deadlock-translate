# 0.6.20 显示自定义补完（2026-10-16）

## 显示与身份

接收显示方式增加“同时显示原生气泡与独立译文区”。三种方式复用同一条翻译任务和结果版本，不重复调用云端服务。聊天记录译文仍保留。独立区时长从首次结果显示开始，精翻不延长时长，已结束条目不重播。

独立翻译栏上方的角色名可开启/关闭，顺序可选“（角色）账号名”或“账号名（角色）”；账号名可独立隐藏。新旧中文角色名沿用译名设置。开关只影响独立翻译栏的信息行，不修改游戏原生 SenderName、原文或玩家账户。原生聊天记录和顶部气泡下方只显示译文，不重复账号或英雄名。

构建时从本机 heroes.vdata_c 的原始 DATA 区和本地各语言资源生成精确别名映射。角色来自游戏顶部玩家栏，经气泡队伍、PlayerIndexN 和原生消息编号关联；旧/自定义控件属性仅作兼容后备。不读取 Ping 的 TargetHeroImage，不根据昵称本身猜英雄。详情见下方角色读取修正章节；未知时独立栏明确显示“未知角色”。

## 大小、位置与上限

- 译文字号沿用原选项，新增不透明度 20～100%。仅改变 Mod 自有控件，不改变原文或父面板淡出。

## 当前候选：原生位置的自有绘制层（2026-10-16）

前面的同步刷新与跨帧高度变化均已被实机否定，本节替代这两段设计。刚才 3 条译文在两次跨帧尝试后仍为 0×0，新的方案不继续修改这些原生容器。该证据说明动态子标签的布局路径失效，不能据此证明具体的引擎内部缓存实现或归责 QOL。

原生显示模式的顶部译文改为自有 DltNativeAnchors 面板的子标签。它与独立栏一样挂在可见游戏根面板下，但位置不采用独立栏设置，而是读取原生 MessageText 和 MessageContents 的实际坐标、尺寸与根 UI 缩放，放在原文下面。读取 GetPositionWithinAncestor，不能使用时尝试 GetPositionWithinWindow 并扣除根面板位置；对象坐标和数组坐标均支持。缺少有限数字、尺寸、缩放或恢复后已在屏幕外时不猜位置，隐藏并记录 geometry 原因。源气泡样式、原文、原生父子结构和高度均不写入。

只有固定最多 10 个叶标签，标签只显示纯译文；超限淘汰最早显示项，迟到精翻不能复活已淘汰项。10 是顶部绘制的固定安全上限，独立栏的条数设置仍作用于独立栏。每次现有回调只检查这 10 个槽位，位置、宽度、透明度签名不变则不重写样式，没有单条消息定时器或绘制动画。原生箭头预留高度可读时用于限制译文高度，避免遮住后一条消息。与原生淡出、隐藏祖先、gScoreboardOpen、gDetailView 相适配，过期/销毁/复用即释放；切局和停用清理自有控件。隐私、纯文本以及原文不变约束与之前相同。

新增 hud-anchor-mounted/layout/unavailable/hidden/retired/displaced 固定阶段；layout 保留原有宽高、增加 anchorX/anchorY 的目标物理坐标，只有有限数字且受范围限制。尺寸非零仍不等于最终画面可见。此更改不修改独立栏的位置配置，不改变翻译请求、模式或上下文，不引入桌面窗口或额外后台。原生位置、游戏 UI 缩放和多气泡遮挡仍需实机验收。

坐标获取失败时，hud-anchor-unavailable 的 count 是固定故障类型：1 根尺寸或缩放无效、2 原文/宿主尺寸未准备好、3 坐标接口不可用、4 原文在屏幕外、5 读取异常。输入框开启时也将几何轮询限制到最多每秒 10 次，新译文不受轮询闸门延迟；空闲位置不更新样式。控件创建失败清理残件并间隔三秒重试，不消耗额外槽位或重复提交翻译。

用户截图确认坐标绘制层会遮到下一条原文，且明确要求修复旧原生方式，因此坐标方案不继续使用。旧方法的问题路径是气泡已建立后，从聊天框脚本跨界面创建标签；之前原生子标签实测为 0×0。该证据尚不足以解释底层引擎实现，但可以改变控件创建阶段与上下文进行对照。

## 预建标签之后的绘制候选（2026-10-16）

本机 23:18 的 3 条任务均成功返回，预建标签已测得 326×39、326×39、326×114，原文/宿主亦有尺寸，未出现 template-missing 或零尺寸。用户仍反馈需要回车刷新，说明几何已进展，但尺寸并不等于最终绘制；不能继续归因模型超时或宣称原生已修好。匿名事件保存于 artifacts/native-template-live-evidence.json。

本候选在实际内容/字号/本标签隐藏状态改变时，只为现有标签交替添加 DltNativePaintA/B，ApplyStyles(true) 也仅作用于这个标签。专用 CSS 动画只改变亮度 1→1.01→1，持续 0.2 秒，animation-frame-time=100ms，iteration-count=1；不修改透明度、位置、尺寸、父节点和全局 HUD，不恢复 QOL 的循环背景动画。相同内容与稳定扫描不重复触发；消息过期、切局或独立模式不会触发新的原生绘制。动画由原生样式系统结束，不增加单条消息计时器。动画帧的实际 GPU 成本仍需游戏验证，不能由 CSS 采样间隔推出 FPS 保证。

读取 BReadyForDisplay / BIsTransparent 只用于诊断，不调用 SetReadyForDisplay。hud-template-paint 为提交前状态，hud-template-render-state 为后续尺寸检查时状态；count 使用固定按位标记：1=就绪接口可读，2=已就绪，4=BIsTransparent 接口可读，8=该接口返回 true，16=visible 为 false，32=本标签透明度为零，64=读回绑定格式，128=读回当前译文，256=读回为空。没有这些位表示该项未知/不满足，不写入实际文本；hud-template-paint-missing 记录局部接口不可用。它们都不是 GPU 可见证明。

同一会话/消息/结果版本/字号/透明度/译文最多提交一次正常绘制，只有自有标签确实被隐藏后允许一次恢复，硬上限两次。变量读回异常或其他脚本反复隐藏也不能把它变成常驻动画。清空译文、切局和模式关闭会清理对应绘制状态。BReadyForDisplay 与 BIsTransparent 是引擎接口的原始读值，不直接等同于 GPU 像素状态。
