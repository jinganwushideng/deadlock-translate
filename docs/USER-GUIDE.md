# 同频 · Deadlock 聊天翻译 Mod — 详细使用说明

## 翻译服务建议

**微软必应（Bing）免密钥网页翻译在实际使用中经常不稳定，可能无法正常翻译。** 有条件建议接入 **DeepSeek V4.1 Flash**：作者使用时响应较快，翻译一条消息的经验费用约为 **人民币 0.01 元（一分钱）**。

上述速度与费用是作者所用接口和场景下的经验，不是固定收费或延迟承诺。实际费用取决于服务商、套餐、输入输出 token、消息长度及携带的聊天上下文；短消息也可能明显低于此金额。以所用服务的账单为准。

在设置页“翻译服务 → 高质量精翻”填写接口地址、API Key 和服务商提供的模型 ID；想避开 Bing 时，将翻译模式设为“仅高质量精翻”。DeepSeek 官方接口当前使用 `deepseek-flash` 调用 V4.1 Flash，第三方平台模型名可能不同，参见[官方模型与计费说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（2026-09-23 核对）。


适用于 Windows 64 位电脑版 Deadlock。本文面向第一次收到安装包的用户；实际版本以设置页左下角或 `build-manifest.json` 为准。

**先读这一段：** 请完整解压安装包，再安装。不要只复制 VPK，不要在压缩包预览窗口里运行程序。大模型 API 密钥需要你自己配置，安装包不提供额度。游戏内设置窗口属于试用功能，若页面不能操作，可先用 `Settings.cmd` 打开浏览器设置页。

## 1. 这个 Mod 能做什么

- 把游戏里已经显示的玩家文字消息翻译成简体中文，并在原文下方显示。
- 默认处理所有玩家可见发言；可以改为仅队友。它不会获取你原本看不到的敌方队内消息。
- 支持快速翻译、大模型精翻、先快后精三种接收模式。
- 支持左 Alt＋空格，把你输入的消息翻译成英文，再交给游戏发送。
- 发送可选仅英文，或在一条消息中发送“原文 | 英文”。
- 带英雄、装备、技能、俄语名称和常见简称词库，可编辑、导入、导出。

它不翻译语音，不自动回复别人，也不在本机运行翻译模型。除词库直接命中的表达外，翻译服务需要联网；聊天原文及精翻上下文会发给你选用的服务商。

## 2. 解压到哪里

选择一个方便长期保留的目录，例如：

```text
D:\DeadlockTranslate
```

解压后，找到其中的 `DeadlockTranslate.exe`。如果解压软件多套了一层文件夹，实际程序可能在：

```text
D:\DeadlockTranslate\DeadlockTranslate-0.3.2\DeadlockTranslate.exe
```

**后面设置 Steam 时，一律使用你实际找到的 EXE 路径，而不是照抄上面的例子。** 不要放在临时解压目录，也不要在设置完启动选项后随意移动或删除这个文件夹。

同一目录内应保留这些内容：

| 文件或目录 | 用途 |
| --- | --- |
| `DeadlockTranslate.exe` | 本地翻译后台，启动后没有独立控制台窗口 |
| `dlt_translate_dir.vpk` | 游戏里的消息读取、译文显示和设置入口 |
| `pairing.key` | 与本包 VPK 配套的本机通信配对文件；不是大模型 API Key |
| `data` | 默认游戏词库 |
| `wwwroot` | 设置页面的程序和样式 |
| `Install.cmd` | 安装 Mod |
| `Launch.cmd` | 一起启动后台和游戏 |
| `Settings.cmd` | 启动/连接后台，打开浏览器设置页 |
| `Uninstall.cmd` | 卸载本 Mod |
| `Manage-Mod.ps1` | 上述安装、卸载入口使用的脚本 |

其他说明与 JSON 文件也建议保留。不要混用不同安装包中的 VPK、配对文件或后台程序。

## 3. 第一次安装

1. 先安装好 Steam 和 Deadlock，并确认原版游戏能正常启动。
2. 完全退出 Deadlock；Steam 可以保持打开。
3. 在解压目录中双击 `Install.cmd`。
4. 等安装器检查游戏目录和现有 Mod。
5. 出现 `Installed:` 及安装路径，且没有报错，才表示安装完成。随后可关闭安装窗口。

安装器会定位 Steam 库，选择未占用的 VPK 编号，不要求你手动把文件改成 `pak90_dir.vpk`。它会记录安装位置，并在需要时添加游戏的 addons 搜索路径。

### 如果提示 Mod 冲突

- **精确资源冲突 / Overlapping chat resources**：其他 Mod 修改了相同聊天资源，安装会停止。记录提示中的具体文件名，先关闭或移走你确认冲突的那个 Mod，再重试。
- **Related mods / 相关聊天或气泡 Mod**：可能存在重复翻译或样式冲突。只有你明确决定保留两者时才输入 `YES` 继续；它不会帮你自动关闭旧翻译功能。
- 不要为了安装本 Mod，批量删除整个 addons 文件夹里的内容。

### 如果没有找到游戏目录

先确认游戏已下载完整，并且使用的是当前 Windows 用户的 Steam。确实无法自动定位时，可以在 PowerShell 中使用以下格式；两处路径都要换成自己的：

```powershell
cd "D:\DeadlockTranslate"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Manage-Mod.ps1" -Action Install -GamePath "E:\SteamLibrary\steamapps\common\Deadlock"
```

`-GamePath` 指向 Deadlock 的顶层游戏目录，它下面应当有 `game` 文件夹，不是直接指向 `citadel` 或 `addons`。

## 4. 先配置翻译服务

第一次使用建议双击 `Settings.cmd`，先在浏览器中完成配置。这个入口也可以在不开游戏时使用。

### 快速翻译

进入“翻译服务”，快速服务默认是 **Bing · 免密钥**，不需要填写大模型密钥。

- 仍然需要互联网连接；它不是离线翻译。
- 免密钥通道可能限流或改变协议，不能保证一直可用。
- 如果你使用 Azure Translator，请自己填写 Azure 密钥和对应区域，再选择 Azure 服务。程序不会因为 Bing 失败就静默切到付费 Azure。

### 高质量精翻

进入“翻译服务 → 高质量精翻”，填写：

1. **API 地址**：服务商给出的 OpenAI / Chat Completions 兼容 BaseURL。不要填官网首页，也不要把密钥拼在 URL 后。
2. **模型名**：填写服务商控制台支持的完整模型标识，不能只写“DeepSeek”或“GPT”。
3. **API 密钥**：填写你自己的可用密钥，并确认对应账号有额度。
4. 点击页面底部的 **保存设置**。

地址格式举例：`https://api.example.com/v1`。这只是格式示例，不是真实可用服务，请换成自己的地址。当前版本要求云端地址使用 HTTPS，地址不能带账号密码、查询参数或片段。

**密钥框保存后留空是正常的。** 页面不会把已有密钥明文显示出来；留空并保存会保留原密钥。只有点击专门的“清除已保存密钥”按钮后再保存，才是主动清除。不同服务商或不同套餐的密钥不要混用，额度和计费以对应服务商为准。

### 怎样确认接口能用

在“概览与翻译 → 试译一句”中选择要测的引擎，输入一个完整句子，例如：

```text
I will join you after clearing this wave.
```

点击“试译”，检查是否得到译文。不要只用 `GG`、`QSR` 等固定词测试联网，因为它们可能直接命中词库，不能证明云端接口正常。试译大模型可能使用你自己的额度。

## 5. 日常怎样启动

### 方法 A：使用 Launch.cmd

双击 `Launch.cmd`，程序会先准备翻译后台，再通过 Steam 启动 Deadlock。无需再单独打开设置页。

通过该方式启动后，正常退出游戏约 10–12 秒，后台会随之关闭；如果等待约 3 分钟仍未启动游戏，后台会结束等待。若只是单独运行 `Settings.cmd` 配置服务，后台可以保持运行，直到你在设置中停止它。

### 方法 B：直接点击 Steam 的“开始”

只需要设置一次：

1. 打开 Steam，进入“库”。
2. 右键 Deadlock，选择“属性”。
3. 在“通用”页面找到“启动选项”。
4. 找到你的 `DeadlockTranslate.exe`，确认它的完整路径。
5. 按下面格式填写启动选项：

```text
"D:\DeadlockTranslate\DeadlockTranslate.exe" --steam-game %command%
```

6. 关闭属性窗口，再点击 Steam 的“开始”。

注意四点：

- 引号内必须是 **你自己的 EXE 完整路径**，不是游戏 EXE，也不是 VPK。
- 使用英文半角双引号，保留 `--steam-game %command%`，不要给 `%command%` 额外加引号。
- 普通原有游戏参数应保留在 `%command%` 后。若原来已有另一个带 `%command%` 的启动器，不要直接叠加，先请对方或本 Mod 作者协助合并。
- 安装包旧开发文档中可能出现开发者电脑上的 `G:\…` 路径，那不是你电脑的固定安装位置，不能直接照抄。

设置好后，Steam 创建的该游戏快捷方式也可沿用这一入口。没有另加登录自启项或常驻游戏监测器。

## 6. 在哪里打开设置

**游戏外：** 双击 `Settings.cmd`，打开系统浏览器设置页。

**游戏里：** 按 Esc，在游戏“设置”附近点击“翻译设置”，打开内嵌窗口。

- 改完配置要点底部“保存设置”，未保存内容可能在关闭后丢失。
- 用窗口标题栏的“关闭”或 Esc 关闭；点击外侧遮罩不关闭窗口。
- 游戏内窗口不会暂停 PvP 对局，适合在安全时机调整。
- 游戏内窗口仍在做兼容性验证。如果出现不能点击、不能输入、空白或连接提示异常，先使用 `Settings.cmd` 配置，并把具体表现反馈给作者。

外框的“尚未收到页面状态”不等于后台一定没启动；页面初始化失败、与后台断连、云端模型调用失败也是不同的问题。

## 7. 收到消息的翻译模式

在“概览与翻译”设置：

| 模式 | 行为 |
| --- | --- |
| 仅快速翻译 | 走快速服务，响应优先 |
| 仅高质量精翻 | 使用你配置的大模型，可能需要等待 |
| 先快译，再精翻 | 先显示快译，再原位更新；精翻失败保留已有快译 |

默认显示游戏里所有玩家的可见文字聊天，包括自己、友军、全体及组队内容。只希望翻译队友时，选择“仅队友”。系统提示、Ping、聊天轮盘及已是中文的消息可能不会再请求翻译，这是正常过滤。

原文保留，译文只在你本机显示，不会因为接收翻译而自动向其他玩家发送任何消息。

## 8. 左 Alt＋空格翻译发送

1. 先用游戏自己的按键打开所需聊天频道。
2. 输入要说的话；中文输入法的候选词要先确认，确保文字已进入聊天框。
3. 按 **左 Alt＋空格**，不是右 Alt。
4. 聊天框收起后继续游戏，后台完成翻译后提交消息。

游戏中的三个频道要分清：

| 游戏输入框提示 | 设置页名称 | 含义 |
| --- | --- | --- |
| 对（友军） | 友军 | 本局友方队伍 |
| 对（队伍） | 队伍（组队） | PARTY 组队频道 |
| 对（所有人） | 全体 | 所有人可见频道 |

普通 Enter 仍按游戏原有方式发送原文，不触发这个组合键功能。选择“自动”发送引擎，只是自动选择精翻或快译，不是自动回复别人。

“发送内容”有两种：

- **仅英文**：例如只发 `Hello`。
- **原文 + 英文**：例如一条消息 `你好 | Hello`，不是分开发两条；同一句原文不因此多调用一次翻译。

默认同时保留 12 条待发送任务，可在“发送翻译”调到 3–32 条；发送翻译默认 3 路并行，可调 1–8。组合内容有 500 字符长度限制，超长时不自动截断，也不发送；请缩短消息。翻译期间如果你又开始编辑新消息，会等待并保护新草稿。频道无法确认时保留原文，不改发到其他频道。

不要因为没立即看到英文就反复按快捷键；先到“发送翻译 → 最近发送任务”检查状态。

## 9. 怎样看“最近发送任务”

| 状态 | 含义与处理 |
| --- | --- |
| 等待翻译 / 翻译中 | 正在排队或请求服务，先等待 |
| 等待游戏提交 | 译文已生成，游戏端尚未提交；可能正在编辑另一条消息 |
| 等待频道确认 | 当前原生目标与任务未确认一致，不会改发全体 |
| 等待前一条发送 | 译文已完成；为保持同一频道的说话顺序，等待前一条提交或失败 |
| 已交给游戏 | 已调用原生提交；最终是否送达仍以实际聊天记录为准 |
| 未发送 | 已失败或过期，看下面“原因”，不会再自动补发 |

“保留内容（未发送）”只是用于复制的已生成文本，不表示仍会自动发出。“发送队列已满”通常是连按太快或此前有任务尚未完成；等待任务结束或过期，不要继续连按。

关闭发送翻译开关会在下一次同步后取消未提交任务，已经交给游戏的消息无法撤回。复制保留内容后，可以自行粘贴到正确频道并用普通 Enter 发送。

## 10. 字号、显示和性能

“显示与性能”可调整译文字号，预览区会随之变化。译文默认使用纸色底、深色字；专名可显示为“中文（English）”。

消息检查间隔默认 200 毫秒。间隔越短，检查越频繁；没有必要为了云端翻译速度把它调到最小，因为网络和模型延迟仍然存在。并发数、超时可在页面允许的范围内调整，先保留默认值即可排查整体功能。

### 多人连续发言时的高频配置

在“显示与性能”点击“填入高频配置”，再点“保存设置”：快速服务总并发 4、大模型总并发 4、发送翻译并发 3、待发送容量 12。并发上限最多 8，容量最多 32；它们都可以单独调整，旧配置不会因升级自动丢失。

接收、发送和试译共用相应的服务总上限。例如大模型总并发是 4，就不是接收 4 条再额外发送 3 条，同时占用最多仍为 4 条。发送还受自身并发限制；各条译文可以同时生成，但同一频道按输入顺序交给游戏。

概览中的并发/排队计数有助于判断积压。提高并发不等于加快单次模型思考；服务商也可能限流。出现 HTTP 429 后会遵守服务冷却，不会持续重试，必要时降低并发。调低上限时已开始的请求会正常结束，因此短时间内正在运行的数量可能仍高于新上限。

若游戏消息一直无法回传，可试“游戏桥接方式 → 页面导航 · 兼容模式”，保存后重启游戏再测。它是兼容选项，不保证更快。

游戏内设置窗口打开时会增加页面渲染工作，关闭时程序会卸载它。实际帧率与显示效果因游戏版本、分辨率和其他 Mod 而异，自动测试不能代替实机检查。

## 11. 术语、简称和自定义词库

在“游戏词库”里搜索英雄、装备、技能、报点或缩写，例如 `QSR`、`MCG`、`MNK`。中文昵称也可帮助英文发送，例如“老七”“炮台姐”“刷新球”。

- 点击“添加词条”后填写原词、中文、必要时填写规范英文名，最后点击“保存词库”。
- “专名”用于英雄、装备等名称；“短语”用于聊天表达。
- 原词不能重复，大小写不同也可能算同一个原词。
- `SS/MS/TB/ES/KD` 等缩写有多种含义，会交给精翻结合语境，不保证在快译里被直接替换。
- 编辑前可点“导出”保存备份。导入 JSON 后，仍要点击“保存词库”才会生效。
- 自定义词库可能优先于新版本默认词库；升级前先导出，避免把自己维护的词条覆盖掉。

## 12. 常见问题

### A. 双击程序后看不到窗口

后台本来就不显示独立控制台。要配置请运行 `Settings.cmd`；要一起启动游戏请运行 `Launch.cmd`，或使用已配置好的 Steam 入口。不要仅靠“有没有黑色窗口”判断运行状态。

### B. 设置页面提示后台未连接

先运行 `Settings.cmd`。浏览器可访问下面的只读健康检查地址：

```text
http://127.0.0.1:17865/health
```

正常时会看到程序名、版本等 JSON。如果能访问，但游戏内外框仍提示未连接，更可能是嵌入页面或状态回传问题；使用浏览器页配置并反馈。健康检查正常不代表云端翻译服务也一定正常。

### C. 只有关闭、刷新能点，网页里的按钮不能点

这是游戏内 HTML 页面兼容问题，不要因此反复重填密钥。先确认后台和 VPK 来自同一最新版安装包，并且更新后重启过游戏；临时使用 `Settings.cmd`，把游戏内具体表现反馈给作者。

### D. 英文译文生成了，但消息没发出去

检查“最近发送任务”的实际状态和“原因”，并区分友军与组队频道。不要只看到保留文本就认为还在等待自动发送。长消息、频道不一致、超时、队列已满都可能导致未发送。

### E. 快捷键不起作用

确认开启了发送翻译、Deadlock 在前台、聊天框已打开且文字已输入完成，使用左 Alt。若“快捷键监听未启动”，先停止后台再通过启动入口重新运行。若其他软件占用同一组合键，先处理那一处冲突。

### F. 模型请求失败、限流或超时

检查 API 地址、模型名、密钥对应的服务/套餐和剩余额度。先保存，再用完整句子试译。一次失败不能证明游戏 Mod 没加载。Bing 免密钥失败时可稍后重试或自行配置其他服务，不要盲目提高并发或频繁重复请求。

### G. Steam 点“开始”后启动失败

检查启动选项里 EXE 路径是否仍存在，是否使用英文引号，以及 `%command%` 是否保留。不要填作者电脑路径。可以先恢复原启动选项，确认原版游戏能启动，再检查 Mod 安装和 `Launch.cmd`。

### H. 安装提示已有安装记录

不要删除记录强行反复安装。先使用原版本的 `Uninstall.cmd` 卸载本 Mod，再安装新包。安装记录用于确定本 Mod 的 VPK 和恢复原配置，不能复制别人电脑的记录来代替。

### I. 更新游戏或安装其他 Mod 后翻译不见了

游戏更新可能改变资源或还原加载配置；其他 Mod 也可能覆盖聊天布局。保留报错和冲突列表，关闭游戏后检查本 Mod 安装状态。不要把旧 `gameinfo.gi` 整个覆盖到新游戏版本上。

## 13. 升级与卸载

### 升级朋友的安装

1. 退出游戏，在设置中停止后台。
2. 导出自定义词库作备份。
3. 使用原版本 `Uninstall.cmd` 卸载本 Mod；配置和密钥会保留。
4. 完整解压新包到固定目录，运行新包的 `Install.cmd`。
5. 如果目录变了，更新 Steam 启动选项里的 EXE 路径。
6. 检查设置页版本、服务配置和词库，再启动测试。

开发者使用的更新脚本与手工复制文件不是同一流程。不要混用新 VPK 与旧后台、旧 `pairing.key`；不要仅覆盖一个文件就当作升级完成。

### 不想继续使用

1. 退出 Deadlock。
2. 在 Steam 启动选项中删除本程序的 `"…DeadlockTranslate.exe" --steam-game %command%` 部分，恢复你原来的普通游戏参数。
3. 在设置页停止后台，再运行 `Uninstall.cmd`。
4. 卸载成功后才移动或删除解压目录。

卸载只处理本 Mod 记录的文件，配置和密钥默认保留。如果安装后的 VPK 或 `gameinfo.gi` 被其他工具改过，卸载器可能拒绝删除或保留文件并给出提示；请记录提示，不要批量删其他 Mod。

## 14. 配置在哪里，哪些不要分享

个人配置通常在当前 Windows 用户目录：

```text
%LOCALAPPDATA%\DeadlockTranslate
```

其中可能包含 `settings.json`、`secrets.dpapi`、`terms.json` 和本机安装记录。密钥由 Windows DPAPI 保护，与用户环境有关，不应复制给朋友使用。

分享时只发作者提供的完整发布 ZIP。朋友自己安装、填写自己的接口与密钥。不要把自己的个人配置目录、安装记录或服务商密钥打进去。默认不持久保存聊天正文；服务运行期间仍会在内存中保留当前任务，精翻会使用相关近期聊天上下文。

## 15. 反馈问题时提供什么

提供版本、具体操作步骤、是哪一个聊天频道、能否打开浏览器设置、最近发送任务的状态/原因，以及是否安装了其他聊天或菜单 Mod。

游戏内窗口的问题请说明：页面是否显示、哪些按钮能点、输入是否有效、关闭后是否恢复游戏操作。可以提供遮住私人信息的截图。**不要发送 API Key、包含登录令牌的完整设置页地址，或整个个人配置目录。** 只报告 `http://localhost:17865` 这样的主机与端口即可。

当前游戏内窗口仍需在不同电脑与游戏版本验证；编译、浏览器测试、自动回归通过，不等于所有机器的游戏内交互都已验证。
