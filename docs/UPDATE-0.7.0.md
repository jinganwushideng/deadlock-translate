# 同频 0.7.0 更新说明

相对 0.6.25 的最终变化：

- **设置界面重新整理**：贴近游戏的暗色纹理、绿色选中态与分组导航，移除紫色新增标记，改善点击定位和排布。
- **三种设置背景**：静态纹理、半透明透景、实时模糊。透景在设置打开时运行，关闭后恢复游戏菜单；普通浏览器使用静态背景。
- **自动保存**：常规设置结束编辑后自动保存，明确显示保存、失败与冲突状态；词库仍单独保存。保留游戏内原位中文输入和自动回填。
- **发送稳定性**：改善第一次翻译发送的关框确认，等待期间的新输入作为独立草稿处理；保留原频道，避免必须再发第二句才能推进。
- **状态更清楚**：最近发送任务区分等待输入、游戏端提交与本机回显，异常时保留内容便于复制与反馈。
- **重载与诊断**：避免重复重载、旧页面信号干扰和无必要的桥接重建，增加脱敏阶段信息。

- **接收兼容**：常规聊天与旧式大厅聊天轮流扫描，避免大量历史消息使大厅新消息长期等待。

## 安装与更新

退出 Deadlock 后运行 **DeadlockTranslate-Setup-0.7.0.exe**，选择“安装 / 覆盖更新”。程序、设置页和游戏 VPK 一起更新，保留配置、密钥、有效证书和用户词库。已有有效证书无需重复安装。

便携方式仍提供运行 ZIP 和压缩包外的 **DeadlockTranslate-Update-0.7.0.cmd**（本地文件名为“覆盖更新.cmd”），放在同一目录后运行更新器；不要只替换后台 EXE。

安装器内置本版简记和旧版历史。QQ群 **923443423** 可反馈问题、获取及时更新；作者 B 站：[ともり_一生](https://space.bilibili.com/332089385)。

## 验证与使用范围

三种背景、重新加载和关闭恢复已在相同功能候选中进行实际游戏检查。0.7.0 正式构建的包验证与安装器检查见随包验证记录。

透景采用游戏侧兼容合成，场景颜色会影响面板观感；静态纹理默认且开销较低。实时模糊的 FPS 与完整闪烁压力测试未作基准测量。游戏端提交和本机回显也不等同于游戏服务器送达。
