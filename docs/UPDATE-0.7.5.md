# 0.7.5 · 词库保存、快速发送与 DeepSeek 用量

- 词库保存后正确刷新状态，两个设置窗口修改不同词条时自动合并，同一词条的冲突保留草稿供选择。
- 连续快速发送按原文与快捷键顺序登记任务，保留原频道，已提交但未观察到回显的分条可手动重试。
- 可以给不同的预设或自定义发送语言设置快捷键，切换仅在本次后台运行中生效。
- 使用 DeepSeek 官方接口时，设置页显示账号余额和本地用量统计，游戏内可显示翻译费用估算。

退出 Deadlock 后使用完整安装器覆盖更新，个人设置、词库与密钥沿用。
余额来自 DeepSeek 官方接口，任务费用根据返回的 Token 用量和官方价格估算。
