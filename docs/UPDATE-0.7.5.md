# 0.7.5 · 词库保存、快速发送与 DeepSeek 用量

- 修复词库保存后的状态提示，多个设置窗口新增不同词条时自动合并，同一词条冲突时保留草稿供选择。
- 修复连续快速发送的原文捕获和顺序问题，恢复游戏原生回车发送与空输入框关闭。未确认回显的分条可手动重试。
- 新增发送语言快捷键，支持分别绑定预设语言和多种自定义语言。本次切换对后续发送生效，重启后台恢复默认语言。
- 设置页、游戏提示与使用说明统一使用「免费翻译」和「大模型翻译」名称。Azure 按账户额度及计费规则使用。
- DeepSeek 官方接口新增账号余额、本次运行、今日及累计用量统计。翻译完成提示预计费用，接收与发送分别计数。
- 统一费用与出装进度弹窗样式，聊天提示独立加载，出装进度和完成提示优先显示，费用提示等待期间暂停计时。
- 接收内容精确命中本次会话最近发送的完整译文或双语组合时，本地复用原文，减少重复调用与 Token 消耗。
- 下载更新最多检测约 6 秒，GitHub 安装包测速达到 512 KB/s 时打开最新发布页，连接失败、超时或过慢时打开夸克网盘。

## 更新方法

退出 Deadlock 后运行完整安装器，选择「安装 / 覆盖更新」。个人设置、词库、密钥和有效证书沿用。安装包文件名为 `DeadlockTranslate-Setup-0.7.5.exe`。

DeepSeek 余额来自官方接口，费用依据返回的 Token 和官方价格估算。缺失用量和无法估价的请求会单独标注。

已通过模拟服务、浏览器回归和安装包校验。游戏显示、按键时序和客户电脑安装结果仍需实机确认。
