# 同频 0.7.1 更新说明

游戏内输入兼容与密钥粘贴（2026-11-04）

相对已发布的 0.7.0：

- 新增顶栏“输入修复”：原生输入接管慢或失败时，可切换网页输入/粘贴；选择在当前设置会话重新加载后保留。
- 补充只收到点击事件时的文字框激活；原生尚未接管前保留网页原框内容，避免出现点击后空白、无反馈。
- 原位坐标或缩放不可用时，改用居中的原生编辑框；输入完成后回填，取消和迟到结果不会覆盖新的网页输入。
- 大模型与 Azure 密钥框新增专用“粘贴密钥”按钮：只在主动点击时读取一次本机剪贴板，绕过游戏浏览器输入限制，沿用遮罩与加密保存。
- 空剪贴板、格式错误或读取失败时保留原密钥；补充输入接管、回传及焦点的脱敏阶段诊断。

## 安装与更新

退出 Deadlock 后运行 **DeadlockTranslate-Setup-0.7.1.exe**，选择“安装 / 覆盖更新”。后台、设置页和游戏 VPK 一起更新；已有配置、密钥、有效证书和用户词库保留。

便携更新：将 **DeadlockTranslate-Update-0.7.1.cmd**（本地文件名为“覆盖更新.cmd”）与运行 ZIP 放在同一目录，运行更新器；不要只替换 EXE。

## 密钥填写

先复制密钥本身，再点击密钥框旁的“粘贴密钥”。不要复制 Bearer 前缀、JSON 或说明文字。保存成功后只显示“已保存 · 留空保持不变”；失败不会清除原密钥。逐字输入可通过程序目录的 Settings.cmd 打开浏览器进行。
