# 同频精简版更新记录

## 0.1.0 · 首个正式版

- 提供接收翻译、发送翻译、游戏词库和作者信息。默认使用免费翻译，可选大模型翻译。接收译文跟随原消息，发送可附上原文，长消息自动分条。
- 退出游戏后运行 `DeadlockTranslate-Lite-Setup-0.1.0.exe`。已有完整版可以直接切换，自动带入个人词库、收发语言、发送快捷键、收发开关、双语选项和大模型服务配置。同一 Windows 用户保存的 API 密钥会一起迁移。
- 已安装早期精简版的用户可直接覆盖升级。大模型服务还没配置时，安装器会带入本机保留的完整版配置和密钥。
- 精简版有独立的版本号和 GitHub 更新通道。在「作者信息」可以检查精简版更新。

本版已校验安装包，并用测试配置验证完整版切换、早期精简版覆盖升级和中断回退。对局内表现仍需实测。
