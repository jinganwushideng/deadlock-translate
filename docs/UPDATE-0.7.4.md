# 0.7.4 · 整套出装翻译与 DeepSeek 预设

- 出装翻译优先读取本地整套方案和游戏完整导出，在后台翻译标题、说明、分组与装备注释，最多两批并行，已译内容按来源校验复用。
- 浏览器预览与商店开关独立；中文方案不自动启动，外文方案按设置自动处理，浏览器列表可以手动一键翻译。
- 修复装备注释显示与切换刷新；固定分组及装备购买率、胜率在本地直译，缓存、本地直译和新译分开计数，失败段落独立补译。
- 翻译服务新增 DeepSeek / 自定义预设。DeepSeek 提供获取密钥入口和 Flash / V4 Pro 模型下拉选项，自定义保留地址和模型手动输入。
- 完善出装语境、术语简称和官方段位译名，Eternus 使用「不朽之星」，已有残留英文的译文缓存可在本地修正。
- 修复 Steam 普通启动被管理员后台接管的问题，保留当前 Steam 的环境、权限和游戏参数，安装器配置启动项时移除旧提权标记。

- 退出 Deadlock 后用完整安装器覆盖更新，后台、设置页和 VPK 成套升级，个人配置、密钥、证书和词库沿用。
- 旧自定义服务地址与模型继续保留；DeepSeek 新配置默认 deepseek-flash，获取密钥按钮打开系统默认浏览器。
- Steam 启动路径已完成隔离 Windows 进程与权限测试，客户机器仍需用本版验证原退出问题。

出装功能基于 PR #1 继续开发并保留其提交历史。后续改动包含本地完整来源、事务缓存、独立预览状态和后台并发调度。
