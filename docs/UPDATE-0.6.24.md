# 0.6.24 更新说明

- 新增更新备份自动管理：更新成功后保留最近两份完整备份，减少旧文件持续占用磁盘。

- 安装器首次打开当前公告时显示一次；同版本公告内容更新后会再次提示，内容不变不重复弹出。

## 备份清理入口

翻译设置 → **诊断与日志 → 更新备份与磁盘占用**。历史备份需勾选“包含旧版留下的完整历史备份”，点击“检查备份占用”后再清理；当前设置、密钥、证书和词库保留。

## API 保活

位置：翻译设置 → 翻译服务 → 大模型 API 保活与预热。默认关闭，保存后生效。间隔支持 60～1800 秒（默认 120 秒）。正常模型请求会顺延保活；游戏断开、无密钥、仅快速翻译或翻译繁忙时不自动请求。

“按已保存配置预热一次”无需开启自动保活，也可在游戏未连接时使用；只使用已保存的有效模型配置，快速连续点击不会重复请求。保活请求不含聊天正文、上下文或词库提示，最多请求 16 个输出 token。支持思考参数的接口只对保活请求关闭思考，真实接收/发送思考与输出预算不变。

失败、断网或限流会延后保活；鉴权失败等待配置修正。保活请求不是聊天消息，不会进入接收/发送队列、消息缓存或真实翻译耗时样本。

DeepSeek 官方没有承诺固定模型驻留周期。上下文缓存通常空闲数小时至数天清理，但不能据此推断模型是否热启动：
https://api-docs.deepseek.com/guides/kv_cache/
