# 同频 0.7.3

- Steam 库所在硬盘断开后，安装器会跳过失效库路径并继续检测其他库。体检不需要先清理 Steam 的库记录。
- GitHub 检查失败或限流时，尝试读取夸克和百度网盘分享的最新版文件夹名。版本高于本机时在概览提醒。
- 游戏翻译设置和安装器的更新页提供三个入口。[GitHub Releases](https://github.com/jinganwushideng/deadlock-translate/releases) · [夸克网盘](https://pan.quark.cn/s/edde8867941a) · [百度网盘](https://pan.baidu.com/s/5vlaAkKuSSR2eTMtVUgCWdQ)

- 安装器显示步骤进度、已等待时间与 Windows 确认状态，检测超时后可以重试，写入阶段可请求安全停止。
- 安装、更新、迁移和卸载记录逐项写入。中断后重开安装器可继续修复或恢复，保留期间被改动的文件。
- 新增一键体检，修复前预览影响范围。安装已完成时可单独重试 Steam 启动项。
- 游戏设置新增正式版本提醒。默认每日检查，可关闭；下载和启动安装器由玩家选择，下载后校验文件。
- 程序目录留空时会使用上次可用位置或建议目录。更换目录时可选当前空目录或上次目录，选择后进入安装预览。
- 安装器切换操作模式时保留当前页面，仅更新相关说明和按钮。顶部「启动项管理」可直接配置多个 Steam 账号。游戏内也可勾选和预览，再转到安装器确认。
- 顶部原生气泡下的译文增加独立纸纹底框、深色细边和短投影，与原文同侧对齐。显示测试使用同样的译文底框。
- 批量配置 Steam 启动项时自动跳过没有 Deadlock 本地记录的账号，其余可配置账号继续处理。单纯缺记录不再留下待恢复安装。
- 安装器顶部新增「浏览器后台设置」，可启动已安装的后台并打开默认浏览器设置页。

安装器首页可体检和处理未完成操作，底部「更多选项」可检查更新。游戏内入口在「诊断与日志」。退出 Deadlock 后再执行涉及文件的修复或更新。

- 退出游戏后运行本版完整安装器进行覆盖更新，后台、设置页和游戏 VPK 会成套更新。
- 体检只检查本机文件、配置与连接。实际游戏收发和显示需启动 Deadlock 验证。
