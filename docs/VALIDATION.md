# 发布验证

正式包的验证结果、版本、构建编号和 SHA256 记录在 release/对应版本/release-verification.json。自动验证与实际游戏验收分别记录。

## 构建与文件

1. 检查版本和构建编号贯穿后台、设置页、VPK、源码包与安装器。
2. 对 VPK 的全部资源进行 CRC 校验，并解码检查实际打包的游戏脚本与布局。
3. 检查便携 ZIP、逐文件清单、公开源码包、外置覆盖更新器以及安装器内置 ZIP 的一致性。
4. 检查压缩网页资源与原始 HTML/JS/CSS 相同，避免浏览器读取到旧内容。
5. 检查公开源码不含个人密钥、聊天、状态目录、证书私钥或生成的原版游戏资源。

## 自动测试

运行与本次变化相关的后台、游戏脚本和设置页测试；安装器覆盖完整解包、历史更新说明、只读启动及隔离环境中的安装/更新/回退。

接口测试使用本机模拟服务和独立状态目录，不消耗真实服务额度，不发送游戏聊天，不修改用户证书信任或 Steam 设置。使用实际安装包进行的只读检查不等同于已经在玩家机器完成安装。

## 游戏验收

在当前游戏版本中检查聊天记录、原生气泡、独立栏、菜单、按键录制、发送频道和分条顺序。测试连续消息、重复文本、乱序响应、断网、切局与窗口切换；检查常用分辨率、长句和其他 Mod 组合。

实际可见性必须由画面确认。非零控件尺寸、写入成功和模拟测试不能代替 GPU 显示结果；脚本墙钟耗时不能换算成帧率提升。正式发布说明只记录最终功能与行为，排查过程保留在工作区 artifacts 中。
