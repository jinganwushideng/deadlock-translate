# 验证范围

## 0.5.0（2026-10-08）

本轮新增发送保留名额、公平调度、共享请求取消隔离、上下文缓存隔离、证书诊断/续期备份、界面节点保留及刷新不重叠测试。完整 HTTP/HTTPS 测试使用隔离数据目录；过期证书下 HTTP 设置仍可访问。没有调用真实翻译 API，也没有通过测试自动改变系统证书信任。游戏内操作与 FPS 仍需实测。历史 0.4.x 的性能数字不代表 0.5.0 的当前结果，发送预留名额开启时接收精翻吞吐量上限会相应降低。

## 2026-09-22 公开源码整理后的验证

从不含历史 artifacts、生成 XML、生成词库、密钥和 node_modules 的源码 ZIP 解压到新目录，使用本机合法安装的游戏和外部工具完成资源重新生成、9 项 Panorama 编译、TypeScript 编译、自包含后台发布、运行时许可收集和 VPK 校验。第一次发布遇到 Windows 文件占用，顺序重试成功；未据此修改防病毒设置或结束游戏进程。

该干净目录中核心 181 项、并发 23 项、Panorama 模拟 27 项、翻译发送模拟 55 项、设置窗口模拟 20 项通过，术语合并和 Steam 启动选项测试通过。源码导出边界、已知凭据格式、个人路径及文档相对链接检查通过。没有调用真实翻译 API、启动游戏或修改已安装 Mod。

GitHub Actions 配置已提供；上述是本地验证，不是远端 GitHub Actions 的执行记录。

## 历史开发记录

0.4.0 开发期间记录的本地结果：核心 181 项、并发 23 项、Panorama 模拟 27 项、翻译发送 UI 模拟 55 项、浏览器 24 项、隔离发布包 HTTP 17 项通过。部分测试依赖构建后生成的词库和隔离后台，不能直接用单个 npm test 复现全部结果。

本地模拟服务中，12 个各延迟 120ms 的请求，单并发约 1493ms、四并发约 378ms。这只是受控 HTTP 模拟，不是公网翻译延迟或游戏帧率数据。

公开源码 CI 只运行无需游戏资源、无需云端服务的检查与测试；准确范围以 `.github/workflows/ci.yml` 为准。CI 不安装 Mod、不启动游戏、不注入密钥、不运行真实 API 测试。

当前游戏版本的队伍/全体发送、游戏内窗口点击和焦点、长译文遮挡、帧率，以及不同 Mod 组合兼容性均需要使用者实测。不要在 README 或 Release 中把模拟通过写成游戏实测通过。
