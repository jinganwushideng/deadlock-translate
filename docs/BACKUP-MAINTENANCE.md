# 更新备份与磁盘占用

此功能为 0.6.24 的补充修订，保留当前版本号。源码和验证结果更新不等于已发布安装包或已覆盖本机安装，交付时单独说明。

## 自动保留

每次更新在替换文件前记录 `in-progress`，完成后台、设置页、VPK 和安装记录的提交校验后记录 `succeeded`。失败记录 `failed`；异常退出留下 `in-progress`，均不自动删除。

成功更新后保留最近两份成功备份。删除旧备份前会校验保留点及候选文件的 SHA-256；校验失败或清理失败不回滚已经成功的更新。发现额外文件、缺失文件、链接或未知用途目录时保留处理。冲突恢复副本、Steam 启动项备份和旧版 GUI 备份不会被通用清理删除。

旧版没有事务结果标记的历史备份默认保护，不自动推断其更新是否成功。

## 手动清理

翻译设置 → **诊断与日志 → 更新备份与磁盘占用**。

1. 点击“检查备份占用”，查看目录数、占用及可清理份数。未检查前不能执行清理。
2. 需要处理旧版积累时勾选“包含旧版留下的完整历史备份”，再重新检查。历史备份需文件清单完整，删除前也会校验哈希。
3. 点击“清理旧备份”。始终保留最近两份符合条件且完整的回退点；不会删除当前配置、密钥、证书、词库或其他 Mod。

预览后目录内容变化会使清理计划失效，要求重新检查。更新和维护使用同一个跨进程文件锁，不能同时写备份。清理一旦确认，会在关闭设置页后继续；后台退出或维护超时会停止，未完成备份受到保护。

占用统计为常规文件逻辑大小，链接/不可读目录可能无法计入全部空间，因此是保守统计。预览只读取文件清单和元数据，不扫描旧程序大文件的内容；删除时才做哈希校验。设置页打开和定时刷新不会触发扫描，维护进程使用较低优先级；实际游戏帧率影响尚未实测。

## 日志及诊断

`%LOCALAPPDATA%\DeadlockTranslate\backup-maintenance.jsonl` 记录清理时间、方式、删除数、释放字节数和失败数，约 128 KiB 后轮转，保留当前及上一份。更新操作日志还会记录自动清理结果。

一键导出的诊断包包含经过字段筛选的 `logs/backup-maintenance.jsonl`，不会复制原始设置、密钥、聊天正文或备份中的程序文件。失败时先导出诊断，再检查权限和文件占用；不要直接删除整个状态目录。
